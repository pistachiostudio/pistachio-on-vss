# theme-swap — 配色を一括で変える

このリポジトリ(pistachio-on-vss)の配色は CSS 変数に一本化されている。
仕組みの詳細は `AGENTS.md` の「カラーテーマの仕組み」を参照。このスキルは
**候補を出す → 選んでもらう → 一括で書き換える → ビルドで確認する** の流れを担当する。

## 流れ

### 1. 現状を確認する

- `static/css/themes.css` の現在のテーマ(`data-theme` のキーと配色、冒頭コメントの過去テーマ名)を読む。
- `layouts/*.html` の `<body data-theme="...">` と `Theme: ...` の表記を確認する。
- ユーザーが雰囲気(「落ち着いた」「夏っぽい」など)を指定していれば、それを候補に反映する。
  指定がなければ、雰囲気の違う候補を幅広く出す。

### 2. 候補を出す(ここで一度止まる)

**4〜5案**を、テーマ名つきで提示する。ユーザーが選ぶまで、ファイルは書き換えない。

- **テーマ名は2単語**にする(例: `Neon Drive`、`Midnight Matcha`)。
  必須ではないので、しっくりくるなら1語や3語でもよい。名前だけでも雰囲気が伝わるものにする。
- 現在のテーマと同じもの、**同名・ほぼ同じ配色の案は出さない**。過去テーマ
  (`themes.css` 冒頭に名前だけ残っているもの)を復活案として1つ混ぜるのはよい。
  その場合は「過去テーマの復活」と明記する。
- 案どうしで系統をばらす(ダーク/ライト、暖色/寒色、ビビッド/くすみ、など)。
- 各案に含めるもの:
  - テーマ名 と 一言の雰囲気説明
  - `data-theme` に使うキー(英小文字・ハイフン区切り。例 `midnight-matcha`)
  - 主要な色(背景 / 本文 / タイトル / リンク / リンクhover / ドットA・B)を hex で
- 見やすさのため、**色見本を視覚的に見せる**。可能なら(`Artifact` や `mcp__visualize__show_widget`
  など、使える表示ツールがあれば)各案を「背景色の上に本文・タイトル・リンクを載せた小さなカード」
  として並べて表示する。使えなければ Markdown の表で hex を並べる。
- 提示前に**コントラストを確認**する(下記)。基準を満たさない案は調整してから出す。

提示の最後に「どれにしますか?(番号/名前で。微調整の希望があれば言ってください)」と聞く。

### 3. 選ばれたテーマを適用する

一括で、次の4か所を書き換える。

1. **`static/css/themes.css`**
   - 配色ブロックを丸ごと新テーマに置き換える(`body[data-theme="<key>"] { ... }`)。
     旧テーマのブロックは **残さない**(コードで溜めない方針)。
   - 冒頭コメントの「過去のテーマ名」リストに、**入れ替える前のテーマ名を1つ追記**する。
   - 使う変数は下の一覧の14個すべてを埋める(抜けると `style.css` の `:root` の既定色が漏れる)。
2. **`layouts/default.html` / `layouts/quojama.html` / `layouts/20230826.html`**
   - `<body data-theme="...">` を新しいキーにする。
   - `<span class="typew">Theme: ...</span>` を新しいテーマ名にする。
   - タイプライターのキャレット `<span style="color:pink;">` が 2か所ある。
     新テーマと喧嘩する場合は、`--doggo-color` か `--link-color` と同系の色に直す。
   - **3ファイルとも同じ内容にする**。
3. **ドットアイコンの色**: `--dot-color-a`(本体) / `--dot-color-b`(目・ハイライト)。
   themes.css の変数で決まるので、別ファイルの修正は不要。
   猫以外の形にしたい要望のときだけ `static/css/dot/cat.css` に触る(要相談)。
4. **`README.md`** の「現在のテーマは **...**(...)」の1行を新テーマ名と説明に更新する。

必要なら `static/manifest.json` の `theme_color` / `background_color` も新しい背景色に
合わせるか、ユーザーに確認する(既定では触らない)。

`style.css` / `vhs.css` に**色を直接書かない**。構造CSSは色を持たない方針。

### 4. 確認する

- `vss build` を実行してエラーがないこと。手元の `vss` が古い場合は `make setup*` で更新。
- `dist/index.html` などに新しい `data-theme` と "Theme: ..." が入っていることを grep で確認。
- 可能なら `vss serve` して実際の見た目を見る(ブラウザ系ツールがあればスクリーンショット)。
  特に、スキャンライン(縦縞)で文字が読みにくくなっていないか確認する。
- `git diff --stat` を見せて、変更が上の4か所(+必要なら manifest)に収まっていることを報告する。

**コミット・プッシュ・PR作成は頼まれたときだけ。** `main` へのマージは本番に即デプロイされる。
作業は `main` 以外のブランチで行う。

## 変数の一覧(themes.css で必ず全部指定する)

| 変数 | 役割 |
| --- | --- |
| `--main-bg-color` | ページ背景 |
| `--main-font-color` | 本文の文字色 |
| `--title-color` | 見出し「Pistachio Studio!」の色 |
| `--link-color` / `--link-hover-color` | リンクの通常/hover |
| `--social-button-color` / `--social-button-hover-color` | ソーシャルアイコンの通常/hover |
| `--selection-text-color` / `--selection-bg-color` | テキスト選択時の文字/背景 |
| `--doggo-color` | 左上付近の点滅する `*` |
| `--vhs-noise-color` | 背景の横線ノイズ(`.lines`)の色 |
| `--vhs-scanline-color` | 走査線アニメーションの色 |
| `--dot-color-a` / `--dot-color-b` | 左上の猫ドット絵の2色 |

`--h5-font-size` / `--h5-margin` / `--h1-text-decoration` は配色ではなくレイアウト調整用の変数。
テーマ変更では基本そのままにする(`themes.css` に書かなくてよい)。

## 配色づくりの指針

- **コントラスト**: 背景に対し、本文・タイトル・リンク・ソーシャルアイコンは WCAG の
  **4.5:1 以上**(大きい文字のタイトルは 3:1 以上)を目安にする。`--selection-*` は
  文字と背景の組で 4.5:1 以上。
- **VHS 演出との相性**: `vhs.css` に RGB ずれの `text-shadow`(赤/緑/青/マゼンタ/シアン系、色は固定)
  が常時かかっている。淡い背景 × 細い文字だとにじんで読みにくいので、ライト系の案は
  文字色を濃くする。
- **走査線**: `--vhs-noise-color` は背景の上に縞を重ねるので、ダーク背景なら黒系、
  ライト背景なら背景より少し濃い色にして、目立ちすぎないようにする。
  `--vhs-scanline-color` は半透明(alpha 0.2〜0.5)が基本。
- **hover**: `--link-hover-color` は通常色と見分けがつく(明度か色相が違う)こと。
- 数値でコントラストを出すには、Node があれば次のワンライナーが使える(hex 2色を渡す):

  ```bash
  node -e 'const L=h=>{const c=[1,3,5].map(i=>parseInt(h.slice(i,i+2),16)/255).map(v=>v<=.03928?v/12.92:((v+.055)/1.055)**2.4);return .2126*c[0]+.7152*c[1]+.0722*c[2]};const [a,b]=process.argv.slice(1).map(L);console.log(((Math.max(a,b)+.05)/(Math.min(a,b)+.05)).toFixed(2))' "#0d0221" "#f5f0ff"
  ```

## 候補の出し方の例(発想の種)

雰囲気の軸を変えて出すと選びやすい。名前は毎回新しく考えること(下は例)。

- ダーク × ビビッド: `Neon Drive`(現行)、`Cyber Sunset`
- ダーク × くすみ: `Midnight Matcha`、`Ember Ash`
- ライト × やわらか: `Cream Soda`、`Paper Mint`
- 寒色: `Ocean Static`、`Glacier Pop`
- 暖色: `Sunset Tape`、`Amber Radio`

サイト名が Pistachio(ピスタチオ)なので、グリーン系を1案入れると外しにくい。
